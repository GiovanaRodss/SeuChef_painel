Anotação da melhoria

Criar nova página para sessões do Analytics

Prioridade: Alta Status: Pendente Área: Marketing / Analytics Página sugerida: /admin/analytics/sessions
Problema atual Hoje o acompanhamento de sessões depende de acessar o Google Analytics fora do painel. Isso deixa os dados de audiência separados dos outros indicadores administrativos do SeuChef.
Como deve funcionar Criar uma nova página no painel para acompanhar as sessões do site. A página deve exibir um gráfico mensal comparando 2025 e 2026.
Ajuste necessário Integrar o painel com o Google Analytics, puxar os dados reais da propriedade GA4 e reproduzir essas informações no painel administrativo.
Requisito técnico

Integração com Google Analytics

O painel precisa ser integrado ao Google Analytics para buscar os dados reais de sessões. Os valores não devem ficar fixos no HTML ou no JavaScript.

Google Analytics Data API Usar a API oficial do Google Analytics para buscar relatórios da propriedade GA4, retornando a métrica de sessões agrupada por mês.
GET/API — Buscar dados iniciais Ao carregar a página, o front-end deve chamar um endpoint interno do painel. Esse endpoint deve consultar o Google Analytics e retornar os dados prontos para o gráfico.
Envio de filtros — Atualizar gráfico Quando o usuário aplicar filtros de período ou ano, o front-end deve enviar esses filtros para a API interna. A API deve consultar novamente o Google Analytics e retornar os dados recalculados.
Não deixar valores fixos Os arrays usados neste HTML são apenas exemplos visuais. Na implementação final, todos os valores precisam vir do Google Analytics.
Fluxo esperado: 1. Usuário acessa Analytics > Sessões. 2. Front-end chama o endpoint interno do painel. 3. Back-end consulta o Google Analytics. 4. Google Analytics retorna as sessões da propriedade GA4. 5. Back-end organiza os dados por mês. 6. Front-end monta o gráfico com os dados retornados. 7. Usuário aplica filtros. 8. Front-end envia os filtros para a API interna. 9. API consulta novamente o Google Analytics. 10. Front-end atualiza o gráfico.
Critério de aceite

Quando considerar essa melhoria concluída

  • Existe uma nova página no painel para acompanhar sessões do Analytics.
  • A página está acessível no menu do painel.
  • O painel está integrado ao Google Analytics.
  • O gráfico exibe sessões por mês.
  • O gráfico compara 2025 e 2026.
  • Os dados vêm da propriedade GA4 real.
  • Os valores não ficam fixos no front-end.
  • Os filtros, se existirem, atualizam o gráfico.
  • Os números exibidos no painel batem com o Google Analytics.
Observação técnica
