Melhoria: gráfico de cadastros na página de empresas

Documento visual para apresentar a alteração necessária na página Operacional > Empresa. A proposta é adicionar um gráfico de cadastros de estabelecimentos por mês, facilitando a leitura do crescimento da base de empresas.

Anotação da melhoria

Adicionar gráfico de cadastros de empresas por mês

Prioridade: Média Status: Pendente Área: Operacional Página: /admin/companies
Problema atual A página de empresas mostra os totais gerais, como total de empresas, empresas com vagas publicadas e empresas sem vagas, mas não mostra de forma clara a evolução mensal de novos cadastros.
Como deve funcionar Adicionar um gráfico de linha mostrando a quantidade de empresas cadastradas por mês. O gráfico deve permitir acompanhar se a base de empresas está crescendo, caindo ou ficando estável.
Ajuste necessário Criar uma seção de gráfico na página Operacional > Empresa, usando os dados de cadastro das empresas agrupados por mês.
Regra de cálculo

Cálculo dos cadastros mensais

O gráfico deve contar quantas empresas foram cadastradas em cada mês, usando a data de criação do cadastro da empresa.

Cadastros do mês = total de empresas com Created dentro daquele mês

O campo usado deve ser o de criação da empresa, não a data da primeira vaga publicada e nem a última atualização do cadastro.

Critério de aceite

Quando considerar essa melhoria concluída

  • A página Operacional > Empresa passa a exibir o gráfico de cadastros por mês.
  • O gráfico mostra os meses de janeiro a dezembro.
  • Os valores são calculados pela data de criação da empresa.
  • O gráfico exibe os valores de cada mês de forma clara.
  • Os meses sem cadastro aparecem como zero ou ficam sem ponto, conforme decisão técnica.
  • O gráfico respeita os filtros de período, caso a página tenha filtro aplicado.
  • Os números batem com a base real de empresas.
Observação técnica

Integração com os dados reais

Na versão final do painel, os dados fixos deste HTML devem ser substituídos pelos dados vindos do banco ou da API do painel.

labels: ["Jan", "Fev", "Mar", "Abr", "Maio", "Jun", "Jul", "Ago", "Set", "Out", "Nov", "Dez"]
cadastros: [33, 40, 33, 34, 25, 0, 0, 0, 0, 0, 0, 0]

O ideal é puxar esses dados dinamicamente conforme o ano selecionado ou o filtro aplicado no painel.
