Anotação da melhoria

Adicionar gráficos de análise na página Operacional > Vaga

Prioridade: Média Status: Pendente Área: Operacional Página: /admin/jobs
Problema atual A página de vagas mostra apenas um gráfico geral de vagas dos últimos 12 meses, mas ainda não oferece uma visão detalhada por tipo de vaga e nem comparação direta entre anos.
Como deve funcionar Adicionar dois novos gráficos na página: um gráfico de barras por tipo de vaga e um gráfico de linha comparando as vagas publicadas em 2025 e 2026.
Ajuste necessário Criar uma seção analítica na página Operacional > Vaga, usando os dados de vagas agrupados por mês, ano e tipo de venda/publicação.
Regras de cálculo

Como os gráficos devem ser calculados

Os gráficos devem usar a data de criação/publicação da vaga e agrupar os resultados por mês.

Gráfico 1: Total de vagas por mês, separadas por tipo de vaga. Gráfico 2: Total de vagas publicadas por mês, comparando 2025 x 2026.

Os tipos esperados para o primeiro gráfico são: vaga avulsa, vaga associada, vaga com cupom, vaga gratuita e vaga de pacote.

Requisito técnico

Dados dinâmicos dos gráficos de vagas

Os dois gráficos da página Operacional > Vaga precisam ser alimentados com dados reais da base. Os valores não devem ficar fixos no HTML ou no JavaScript.

GET/API — Buscar dados iniciais Ao carregar a página, o front-end deve fazer uma requisição para buscar os dados reais da base e montar os gráficos iniciais. A API deve retornar os dados já agrupados por mês, ano e tipo de vaga.
Envio de filtros — Atualizar dados dos gráficos Quando o usuário aplicar filtros na página, como período, ano, tipo de vaga, status, empresa, cidade ou estado, o front-end deve enviar esses filtros para a API para recalcular os dados.
Retorno esperado da API A API deve retornar os valores já tratados para os gráficos. O front-end deve apenas receber os dados, montar os labels e atualizar a visualização.
Não deixar valores fixos Os arrays usados neste HTML são apenas exemplos visuais. Na implementação final, todos os valores precisam vir da base de dados do painel.
Fluxo esperado: 1. Usuário acessa Operacional > Vaga. 2. Front-end faz GET/API para buscar os dados iniciais dos gráficos. 3. API consulta a base e retorna os dados agrupados por mês. 4. Front-end monta os gráficos com os dados retornados. 5. Usuário aplica filtros na tela. 6. Front-end envia os filtros para a API. 7. API retorna os dados recalculados. 8. Front-end atualiza os gráficos.
Critério de aceite

Quando considerar essa melhoria concluída

  • A página Operacional > Vaga passa a exibir o gráfico de vagas por tipo.
  • A página passa a exibir o gráfico comparativo de vagas publicadas por ano.
  • Os dados são agrupados corretamente por mês.
  • O gráfico de tipos separa avulsas, associadas, cupom, gratuitas e pacotes.
  • O gráfico comparativo diferencia claramente 2025 e 2026.
  • Os dados são puxados da base por API/GET ou endpoint equivalente.
  • Os filtros aplicados na tela atualizam os gráficos.
  • Os valores não ficam fixos no front-end.
  • Os números batem com a base real de vagas.
